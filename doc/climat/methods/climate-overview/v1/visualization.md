# Conception de l’infographie — Climate Overview V1

## But

Donner en quelques secondes une image du **climat habituel** du lieu avant toute lecture du changement climatique.

## Message visuel principal

Le lecteur doit comprendre le rythme annuel : quand il fait habituellement plus chaud, plus froid, plus sec ou plus humide.

## Organisation

Une seule figure mensuelle de janvier à décembre :

- barres de précipitations moyennes ;
- courbe de température moyenne ;
- enveloppe P10–P90 discrète ;
- deux axes explicitement nommés.

Les deux grandeurs restent distinctes : aucune règle ombrothermique implicite n’est appliquée.

## Synthèse

Afficher au maximum quelques repères :

- température moyenne annuelle ;
- précipitations annuelles ;
- mois le plus chaud / froid ;
- mois le plus humide / sec.

## Hiérarchie

```text
cycle annuel
↓
variabilité habituelle
↓
quelques repères synthétiques
```

## Interdits graphiques

Ne pas suggérer :

- une évolution climatique ;
- une précision de station ou de parcelle ;
- des extrêmes thermiques non calculés avec Tmin/Tmax ;
- une relation arbitraire entre °C et mm.

## Critère d’acceptation

Sans texte extérieur, le lecteur doit pouvoir décrire en moins d’une minute le rythme thermique et pluviométrique habituel du lieu.
